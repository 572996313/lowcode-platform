# 低代码平台功能验证指南

## 🚀 快速开始

### 1. 确认服务状态

确保以下服务正常运行：
- ✅ 前端服务：**http://localhost:3002**
- ✅ 后端API：http://localhost:8765
- ✅ MySQL数据库：localhost:3306/lowcode_platform
- ✅ Redis缓存：localhost:6379

### 2. 访问应用

在浏览器打开：**http://localhost:3002**

---

## 📋 功能验证清单

### ✅ 模块1：数据集管理

**访问路径：** 登录后 → 左侧菜单 → 低代码配置 → 前端 → 📊 数据集管理

**验证步骤：**

1. **查看数据集列表**
   - 应该看到预置的2个数据集：
     - `user_dataset` (用户数据集)
     - `menu_dataset` (菜单数据集)

2. **创建新数据集（从表）**
   - 点击"新建数据集"按钮
   - 选择"从表创建"
   - 数据源类型：选择"table"
   - 表名：输入 `sys_user`（或你数据库中的任意表）
   - Schema：输入 `lowcode_platform`
   - 点击"扫描字段"
   - 应该自动显示该表的所有字段信息

3. **测试数据源执行**
   - 选择一个数据集
   - 点击"执行"按钮
   - 应该显示该数据集的数据（分页）

---

### ✅ 模块2：表单设计器（新版）

**访问路径：** 左侧菜单 → 低代码配置 → 前端 → 📝 表单设计器（新版）

**验证步骤：**

1. **步骤1：选择数据集**
   - 选择 `user_dataset` 数据集
   - 查看数据集预览（字段列表）
   - 点击"下一步"

2. **步骤2：配置字段组件**
   - 左侧会显示所有可用字段
   - 为字段选择组件类型：
     - `username` → 文本输入框
     - `email` → 邮箱输入框
     - `status` → 开关或下拉框
   - 点击"下一步"

3. **步骤3：配置字段属性**
   - 设置字段标签、占位符、是否必填
   - 设置列宽（span）
   - 点击"下一步"

4. **步骤4：保存配置**
   - 输入表单名称：如"用户信息表单"
   - 输入表单编码：如`user_info_form`
   - 点击"保存"

5. **预览效果**
   - 保存后会返回表单列表
   - 点击某个表单的"预览"按钮
   - 应该看到渲染出的表单组件

---

### ✅ 模块3：表格设计器（新版）

**访问路径：** 左侧菜单 → 低代码配置 → 前端 → 📊 表格设计器（新版）

**验证步骤：**

1. **步骤1：选择数据集**
   - 选择 `user_dataset` 数据集
   - 点击"下一步"

2. **步骤2：配置表格列**
   - 勾选要显示的列（如：id, username, email, createTime）
   - 为每列配置：
     - 列宽
     - 对齐方式
     - 是否固定
     - 格式化器（如：createTime选择日期时间格式化）
   - 点击"下一步"

3. **步骤3：配置表格属性**
   - 设置表格尺寸（medium/small）
   - 是否显示边框
   - 是否支持排序
   - 点击"下一步"

4. **步骤4：保存配置**
   - 输入表格名称：如"用户列表表格"
   - 输入表格编码：如`user_list_table`
   - 点击"保存"

---

### ✅ 模块4：页面设计器（新版）

**访问路径：** 左侧菜单 → 低代码配置 → 前端 → 📄 页面设计器（新版）

**验证步骤：**

1. **步骤1：选择数据集**
   - 选择 `user_dataset` 数据集
   - 点击"下一步"

2. **步骤2：配置显示字段**
   - 勾选要显示的字段
   - 使用上移/下移按钮调整字段顺序
   - 点击"下一步"

3. **步骤3：配置页面属性**
   - 页面名称：如"用户管理页面"
   - 页面编码：如`user_manage_page`
   - 布局类型：选择"上下布局"
   - 路由路径：如`/user-manage`
   - 点击"下一步"

4. **步骤4：保存配置**
   - 确认所有配置
   - 点击"保存页面"
   - 可选择是否立即发布

5. **预览页面**
   - 保存成功后，点击"预览"按钮
   - 应该看到完整的页面（包含搜索区、表格、工具栏）

---

### ✅ 模块5：数据字典管理

**访问路径：** 左侧菜单 → 低代码配置 → 前端 → 📚 数据字典管理

**验证步骤：**

1. **查看字典分类**
   - 左侧树形结构显示字典分类
   - 预置示例：
     - 用户类型
     - 状态
     - 性别

2. **创建新字典分类**
   - 点击"新建分类"按钮
   - 输入分类名称：如"订单状态"
   - 输入分类编码：如`order_status`
   - 点击"确定"

3. **添加字典项**
   - 在左侧点击某个分类
   - 点击右上角"⋮" → "添加项"
   - 输入标签：如"待支付"
   - 输入值：如`0`
   - 选择颜色：如橙色
   - 点击"确定"

4. **编辑/删除字典**
   - 点击分类或字典项后的"⋮"
   - 选择"编辑"或"删除"

---

### ✅ 模块6：字段联动配置

**访问路径：** 左侧菜单 → 低代码配置 → 前端 → 🔗 字段联动配置

**验证步骤：**

1. **查看联动规则**
   - 应该看到预置的4条规则：
     - VIP用户显示等级
     - 国家省份联动
     - 邮箱通知必填
     - 审核后只读

2. **创建新联动规则**
   - 点击"新建联动规则"按钮
   - 规则名称：如"启用注册时间"
   - 规则编码：如`show_register_time`
   - 源字段：如`userType`
   - 目标字段：如`registerTime`
   - 联动类型：选择"显示/隐藏"

3. **配置触发条件**
   - 操作符：选择"等于"
   - 比较值：输入`admin`

4. **配置执行动作**
   - 显示状态：打开开关（显示）

5. **保存规则**
   - 点击"保存"按钮
   - 规则应该出现在列表中

## 🎯 完整场景测试

### 场景：创建一个完整的用户管理页面

**目标：** 从零开始创建一个包含CRUD功能的用户管理页面

**步骤：**

1. **创建数据集**
   - 进入数据集管理
   - 创建基于 `sys_user` 表的数据集
   - 命名为`用户管理数据集`

2. **设计表单**
   - 进入表单设计器
   - 使用"用户管理数据集"
   - 配置字段：username, email, phone, status, createTime
   - 保存为"用户信息表单"

3. **设计表格**
   - 进入表格设计器
   - 使用"用户管理数据集"
   - 配置列显示
   - 保存为"用户列表表格"

4. **设计页面**
   - 进入页面设计器
   - 使用"用户管理数据集"
   - 选择布局：上下布局
   - 关联表单和表格配置
   - 保存并发布

5. **预览页面**
   - 在页面列表中点击"预览"
   - 验证功能：
     - ✅ 搜索功能
     - ✅ 列表显示
     - ✅ 新增功能
     - ✅ 编辑功能
     - ✅ 删除功能

## 🐛 常见问题

### 问题1：菜单不显示
**解决：** 刷新页面或清除浏览器缓存

### 问题2：数据源扫描失败
**解决：**
- 确认MySQL连接正常
- 检查表名是否正确
- 查看后端日志

### 问题3：预览页面空白
**解决：**
- 确认页面已发布
- 检查路由配置
- 打开浏览器控制台查看错误

### 问题4：字段组件无法选择
**解决：**
- 确认已选择数据集
- 等待字段加载完成
- 刷新页面重试

### 问题5：访问不到前端页面
**解决：**
- 确认访问地址：**http://localhost:3002**
- 检查前端服务是否启动
- 检查浏览器控制台错误
