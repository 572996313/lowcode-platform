## 🧪 功能测试

### 1. 数据集管理

**步骤：**
1. 点击"数据集管理"
2. 点击"新建数据集"
3. 选择"从表创建"
4. 输入信息：
   - 数据集名称：`用户数据集`
   - 数据集编码：`user_test`
   - Schema：`lowcode_platform`
   - 表名：`sys_user`
5. 点击"扫描字段"
6. 点击"执行"测试数据源

**预期结果：**
- [ ] 字段列表自动显示（id, username, email等）
- [ ] 字段类型正确映射（string/number/date等）
- [ ] 执行成功返回数据

### 2. 表单设计器

**步骤：**
1. 点击"表单设计器（新版）"
2. 选择数据集：`user_test`
3. 点击"下一步"
4. 选择字段并配置控件：
   - username → 输入框
   - email → 邮箱输入框
5. 点击"下一步"
6. 配置表单属性：
   - 表单名称：`用户信息表单`
   - 表单编码：`user_form`
   - 表单类型：新增表单
7. 点击"下一步"
8. 确认配置，点击"保存表单"

**预期结果：**
- [ ] 字段列表正确显示
- [ ] 控件类型可选择
- [ ] 控件预览正常显示
- [ ] 保存成功

### 3. 表格设计器

### 5. 数据字典管理

**步骤：**
1. 点击"数据字典管理"
2. 点击"新建分类"
3. 输入：
   - 分类名称：`用户状态`
   - 分类编码：`user_status`
4. 点击"确定"
5. 选择左侧刚创建的分类
6. 点击"⋮" → "添加项"
7. 输入：
   - 标签：`启用`
   - 值：`1`
   - 颜色：绿色
8. 点击"确定"

**预期结果：**
- [ ] 分类显示在左侧树形结构
- [ ] 字典项显示在右侧表格
- [ ] 颜色正确显示

### 6. 字段联动配置

**步骤：**
1. 点击"字段联动配置"
2. 应该看到预置的4条规则
3. 点击"新建联动规则"
4. 输入：
   - 规则名称：`测试联动`
   - 规则编码：`test_linkage`
   - 源字段：`userType`
   - 目标字段：`status`
   - 联动类型：显示/隐藏
5. 配置触发条件：
   - 操作符：等于
   - 比较值：`admin`
6. 配置执行动作：
   - 显示状态：开启
7. 点击"保存"

**预期结果：**
- [ ] 规则列表正确显示
- [ ] 新规则保存成功
- [ ] 规则配置完整
