## 🚀 如何使用

### 访问系统
1. 前端：http://localhost:3000
2. 后端API文档：http://localhost:8765/doc.html
3. Druid监控：http://localhost:8765/druid

### 新增菜单（已添加到左侧菜单栏）
1. **数据集管理** - 管理数据集配置
2. **页面设计器（新版）** - 设计页面布局
3. **表单设计器（新版）** - 设计表单字段控件
4. **表格设计器（新版）** - 设计表格列显示

### 快速上手

#### 1. 创建数据集
```
1. 进入"数据集管理"
2. 点击"创建数据集"
3. 选择数据源类型（如：数据库表）
4. 填写表信息（Schema: lowcode_platform, 表名: sys_user）
5. 点击"创建"，系统自动扫描表结构
6. 点击"查看字段"查看提取的字段元数据
```

#### 2. 设计表单
```
1. 进入"表单设计器（新版）"
2. 选择数据集（如：用户数据集）
3. 配置每个字段的控件类型和属性
   - 用户名 → 输入框（必填）
   - 邮箱 → 输入框
   - 状态 → 下拉框（选项：启用/禁用）
4. 配置表单属性（表单名称、类型、布局）
5. 保存表单配置
```

#### 3. 设计表格
```
1. 进入"表格设计器（新版）"
2. 选择数据集（如：用户数据集）
3. 配置列显示
   - ID → 宽度80，居中，左侧固定
   - 用户名 → 宽度150，左对齐
   - 状态 → 宽度100，居中，标签格式化
4. 配置表格属性（分页、边框、选择等）
5. 保存表格配置
```

## 🛠️ 技术架构

### 核心设计原则

#### 1. 数据与展示分离
```
数据定义层                    展示层
数据集配置 ──────→ 页面/表单/表格配置
    ↑                      ↓
    └──── 通过 datasetId 引用
```

**优势：**
- 同一数据集可被多个页面复用
- 数据源变更只需更新数据集
- 展示变更不影响数据定义

#### 2. 自动化字段提取
- 自动扫描数据库表结构
- 智能映射数据库类型
- 自动提取字段注释、主键等

#### 3. 统一的数据源执行接口
```java
Map<String, Object> executeDataSource(Long datasetId, Map<String, Object> params)
```

支持4种数据源：table/view/sql/api
