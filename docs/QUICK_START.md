# 低代码平台快速入门指南

## 🎯 系统概览

本低代码平台采用**数据驱动架构**，核心思想是：
- **后端定义数据**：通过数据集管理定义"有什么数据"
- **前端定义展示**：通过设计器配置"怎么展示数据"
- **运行时合并渲染**：系统自动合并数据定义和展示配置进行渲染

---

## 📦 核心概念

### 1. 数据集（Dataset）
数据集是数据的来源，支持4种类型：
- **数据库表**：直接关联数据库表
- **视图**：关联数据库视图
- **SQL查询**：自定义SQL语句
- **API接口**：调用外部API

**关键特性：**
- ✅ 自动扫描表结构，提取字段元数据
- ✅ 智能类型映射（VARCHAR→string、INT→number等）
- ✅ 支持动态参数查询
- ✅ 统一的执行接口

### 2. 字段元数据（Field Metadata）
字段元数据描述字段的属性：
- **字段名称**：对应数据源字段
- **字段标签**：显示名称
- **字段类型**：string/number/date/datetime/boolean/json/text
- **数据类型**：VARCHAR/INT/DATETIME等（数据库类型）
- **是否可空**：字段约束
- **默认值**：字段默认值
- **是否主键**：主键标识

### 3. 页面配置（Page Config）
页面配置定义页面的展示方式：
- **显示字段**：选择要显示哪些字段
- **布局类型**：上下布局/树表布局/标签页/自由画布
- **路由路径**：页面访问URL
- **发布状态**：是否发布运行

### 4. 表单配置（Form Config）
表单配置定义表单的渲染方式：
- **字段控件映射**：每个字段对应什么控件（输入框/下拉框/日期选择器等）
- **控件属性**：占位符、是否必填、列宽等
- **布局类型**：水平/垂直/网格等
- **表单类型**：新增/编辑/搜索/详情

### 5. 表格配置（Table Config）
表格配置定义表格的展示方式：
- **列显示配置**：每列的宽度、对齐方式、格式化器
- **表格属性**：分页、边框、排序等
- **格式化器**：标签/日期/图片等数据格式化

## 🚀 快速开始

### 第一步：登录系统

1. 打开浏览器访问：**http://localhost:3002**
2. 输入用户名和密码
3. 登录成功后，看到左侧菜单栏

### 第二步：创建数据集

**目标**：创建一个用户管理数据集

1. 点击菜单：**低代码配置** → **前端** → **📊 数据集管理**
2. 点击"新建数据集"按钮
3. 选择"从表创建"
4. 填写信息：
   - 数据集名称：`用户管理数据集`
   - 数据集编码：`user_dataset`
   - Schema：`lowcode_platform`
   - 表名：`sys_user`
5. 点击"扫描字段"按钮
6. 系统自动显示字段列表（id, username, email等）
7. 点击"确定"保存

✅ **数据集创建成功！**

### 第三步：设计表单

**目标**：创建用户信息表单

1. 点击菜单：**低代码配置** → **前端** → **📝 表单设计器（新版）**
2. **步骤1：选择数据集**
   - 选择 `user_dataset`
   - 点击"下一步"
3. **步骤2：配置字段组件**
   - 勾选字段：username, email, phone, status
   - 为每个字段选择控件：
     - username → 文本输入框
     - email → 邮箱输入框
     - phone → 手机号输入框
     - status → 开关（switch）
   - 点击"下一步"
4. **步骤3：配置字段属性**
   - username：必填✓、占位符"请输入用户名"
   - email：必填✓、占位符"请输入邮箱"
   - phone：占位符"请输入手机号"
   - status：标签"启用状态"
   - 点击"下一步"
5. **步骤4：保存配置**
   - 表单名称：`用户信息表单`
   - 表单编码：`user_info_form`
   - 点击"保存"

✅ **表单创建成功！**

### 第四步：设计表格

**目标**：创建用户列表表格

1. 点击菜单：**低代码配置** → **前端** → **📊 表格设计器（新版）**
2. **步骤1：选择数据集**
   - 选择 `user_dataset`
   - 点击"下一步"
3. **步骤2：配置表格列**
   - 勾选列：id, username, email, phone, status, createTime
   - 配置列属性：
     - id：宽度80、居中对齐、固定左侧
     - username：宽度150、左对齐、可排序
     - email：宽度200、左对齐
     - createTime：宽度160、居中对齐、格式化器"日期时间"
   - 点击"下一步"
4. **步骤3：配置表格属性**
   - 表格尺寸：medium
   - 显示边框✓
   - 显示序号✓
   - 点击"下一步"
5. **步骤4：保存配置**
   - 表格名称：`用户列表表格`
   - 表格编码：`user_list_table`
   - 点击"保存"

✅ **表格创建成功！**

### 第五步：设计页面

**目标**：创建完整的用户管理页面

1. 点击菜单：**低代码配置** → **前端** → **📄 页面设计器（新版）**
2. **步骤1：选择数据集**
   - 选择 `user_dataset`
   - 点击"下一步"
3. **步骤2：配置显示字段**
   - 勾选要显示的字段（全部或部分）
   - 使用 ↑↓ 按钮调整顺序
   - 点击"下一步"
4. **步骤3：配置页面属性**
   - 页面名称：`用户管理页面`
   - 页面编码：`user_manage_page`
   - 布局类型：上下布局
   - 路由路径：`/user-manage`
   - 点击"下一步"
5. **步骤4：保存配置**
   - 确认配置信息
   - 点击"保存页面"
   - 发布状态：打开✓

✅ **页面创建成功！**

### 第六步：预览页面

1. 在页面列表中，找到刚创建的"用户管理页面"
2. 点击"预览"按钮
3. 查看渲染效果：
   - ✅ 顶部搜索区
   - ✅ 中间工具栏（新增/编辑/删除按钮）
   - ✅ 底部数据表格
   - ✅ 分页控件

## 🎨 高级功能

### 1. 数据字典

用于管理枚举值，如状态、类型等。

**应用场景**：
- 用户状态：启用/禁用
- 订单状态：待支付/已支付/已完成
- 性别：男/女/未知

**使用步骤**：
1. 进入 **数据字典管理**
2. 创建分类（如"用户状态"）
3. 添加字典项（标签"启用"，值"1"，颜色绿色）
4. 在设计器中引用字典

### 2. 字段联动

实现字段间的动态交互，如：
- 当用户选择"VIP"时，显示"等级"字段
- 当国家选择"中国"时，省份显示中国省份
- 当邮箱通知打开时，邮箱地址变为必填

**使用步骤**：
1. 进入 **字段联动配置**
2. 创建联动规则
3. 设置触发条件（源字段、操作符、比较值）
4. 设置执行动作（目标字段、动作类型）

### 3. 格式化器

表格列支持多种格式化器：

| 格式化器 | 说明 | 示例 |
|---------|------|------|
| 文本 | 纯文本显示 | 普通文本 |
| 标签 | 带颜色的标签 | 状态：启用（绿色） |
| 徽章 | 徽章样式 | 数量：5（红色徽章） |
| 日期 | 日期格式化 | 2024-01-01 |
| 日期时间 | 日期时间格式化 | 2024-01-01 12:00:00 |
| 图片 | 图片展示 | 头像、商品图 |
| 链接 | 可点击链接 | 跳转详情 |

### 4. 布局类型

页面支持多种布局：

| 布局类型 | 说明 | 适用场景 |
|---------|------|---------|
| 上下布局 | 上搜索、下表格 | 标准CRUD页面 |
| 树表布局 | 左树右表 | 分类管理、部门管理 |
| 标签页 | 多标签页 | 复杂信息展示 |
| 自由画布 | 自由拖拽布局 | 仪表盘、大屏 |

## 💡 最佳实践

### 1. 数据集命名规范

- ✅ 好的命名：`user_dataset`（用户数据集）、`order_dataset`（订单数据集）
- ❌ 不好的命名：`dataset1`、`test`

### 2. 字段标签配置

- 为字段配置清晰的标签（如"用户名"而非"username"）
- 添加必要的描述信息
- 设置合理的占位符

### 3. 表格列宽优化

- ID字段：80-100px
- 用户名/姓名：100-150px
- 邮箱/手机号：150-200px
- 日期时间：160-180px
- 状态/类型：80-100px

### 4. 布局选择建议

- **简单CRUD**：上下布局
- **分类管理**：树表布局
- **多信息展示**：标签页布局
- **数据可视化**：自由画布

### 5. 表单控件选择

| 字段类型 | 推荐控件 | 说明 |

| 用户名/姓名 | 文本输入框 | 简单文本 |

| 邮箱 | 邮箱输入框 | 格式验证 |
| 手机号 | 手机号输入框 | 格式验证 |
| 状态（二值） | 开关 | 启用/禁用 |

## 🔧 常见问题

### Q1：数据集扫描失败？

**A**：检查以下几点：
- 确认MySQL连接正常
- 确认表名和Schema正确
- 确认数据库用户有权限访问INFORMATION_SCHEMA

### Q2：预览页面空白？

**A**：
- 确认页面已发布
- 检查浏览器控制台错误
- 确认路由路径正确

### Q3：字段类型映射不正确？

**A**：
- 系统自动映射MySQL类型到通用类型
- 如需修改，可在数据库中手动调整字段元数据
- 或联系开发者添加自定义映射规则

### Q4：如何修改已创建的配置？

**A**：
- 目前版本暂不支持编辑
- 可删除后重新创建
- 后续版本会添加编辑功能
